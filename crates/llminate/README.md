# llminate

> **to LLMinate** — to probe and test an LLM.

CLI to talk to any OpenAI-compatible LLM server (vLLM, SGLang, ...), with support for
multiple named targets (different base URLs / several GB10 boxes).

See the [repository README](https://github.com/WillIsback/llminate) for full docs.

```
cargo install llminate
llminate --help
```
